# Orbit — early public beta

A macOS utility with a radial tool menu, trackpad brightness control and useful local tools.

**[Download Orbit and read the installation guide](https://orbit-trackpad-beta.pages.dev/)**

Free early beta for Apple Silicon Macs running macOS 26.0 or later. Built-in Force Touch trackpad intended. Ad-hoc signed, unnotarized and unsandboxed; other Mac models still need testing. Read the limitations before downloading.

## Feedback

[Report a bug or usability problem](https://github.com/Sandeep1519-droid/orbit-beta/issues/new/choose). Reports are public. Include Orbit version/build, Mac model/chip (never serial number), macOS version, reproduction steps, expected and actual result. Use sample content. Never share passwords, private documents, complete logs or account details.

[Outside-Mac tester checklist](https://orbit-trackpad-beta.pages.dev/testing.html). Unchecked means untested; universal compatibility is not promised.

For a possible security vulnerability, do not post exploit details publicly. Use the repository's private security reporting route when available; otherwise contact your beta distributor privately.

This repository contains release notes and feedback templates, not the app source. No automatic telemetry, paid API, payment or expiry system. Image search contacts providers and publishers; read the [privacy guide](https://orbit-trackpad-beta.pages.dev/privacy.html).
